NRF27 · Print kit tool

Dot grid print generator

A panel for Illustrator, InDesign and Figma that puts the NRF27 dot grid on the page you're working on. It finds your type and logos, keeps them clear, and draws print-ready dots in Spot UV or PMS 9285C.

Install (macOS, about a minute)

  1. Download the zip above and double-click it to unzip. You get a folder called nrf27-dotgrid-panel in Downloads.
  2. Open Terminal and paste this line, then press Return:
    bash ~/Downloads/nrf27-dotgrid-panel/install.sh
    It copies the panel into your Adobe extensions folder and allows unsigned panels to load.
  3. Quit and reopen Illustrator or InDesign.
  4. Open the panel from Window › Extensions › NRF27 Dot Grid.

Needs Illustrator 2021+ or InDesign 2022+. To uninstall: bash ~/Downloads/nrf27-dotgrid-panel/install.sh --remove

Figma plugin

  1. Download the Figma plugin zip above and unzip it (folder nrf27-dotgrid-figma).
  2. In the Figma desktop app: Plugins › Development › Import plugin from manifest… and pick manifest.json in that folder.
  3. Run it from Plugins › Development › NRF27 Dot Grid. It works on the selected top-level frame.

Same engine and controls as the Adobe panel. Dots are drawn as one vector layer, NRF27 dot grid, always filled with #F6F5EF (colour style NRF27/Dot grid), with no treatment to choose. Figma has no spot colours or overprint, so it's for layouts, comps and screens. Use the Adobe panel for Spot UV / PMS 9285C print files. Name any layer “keep clear” to reserve space, or put dg:ignore in a layer name to skip it.

Using the panel

1 · Pick the page

The panel follows the active artboard or page. It reads the content, ignores full-bleed backgrounds and the spot UV layer, and shows a live preview.

2 · Choose the fade

Full page: dots everywhere, shrinking around the content, with an even gap all round. Corner / edge: dots start at a corner or edge and fade out by the reach.

3 · Keep things clear

Content is avoided automatically. Drag on the preview to add a keep-clear box, click a detected item to ignore it, or use Add selection.

4 · Apply

Spot UV: 100% "Spot UV" spot swatch on the spot UV layer, set to overprint. Colour: "PMS 9285C" spot swatch. Either way, dots fade by size, never by tint. Apply again to replace.

The grid scales with the page (u = long side ÷ 1440, as on the NRF27 landing page). Dots stay inside the trim, never in the bleed. Settings are saved on the grid, so reopening the panel restores them.
